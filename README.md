# Portafolio full-stack: plan de acción

Plan de trabajo de tres proyectos para mi portafolio, orientados a un puesto de desarrollador full-stack web.

| Proyecto | Qué demuestra | Stack previsto |
|---|---|---|
| **TaskFlow** (`taskflow-kanban`) | Producto SaaS completo: auth, roles, tiempo real | Next.js, TypeScript, Node, PostgreSQL, WebSockets |
| **DataPulse** (`datapulse-api`) | Diseño de APIs, caché, rate limiting, dashboard | FastAPI/Fastify, Redis, PostgreSQL, React |
| **DocuChat** (`docuchat-ai`) | Integración de LLMs con RAG y streaming | Next.js, FastAPI, pgvector, API de Claude |

El detalle de fases, criterios de éxito y calendario está en [`plan-de-accion-portafolio.txt`](plan-de-accion-portafolio.txt).

Cada proyecto se considera terminado cuando tiene README, tests, CI, Docker y demo desplegada.
